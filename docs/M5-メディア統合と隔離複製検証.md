# M-5 メディア12モデルの統合と隔離複製検証

メディア12モデル（画像4・動画4・音声4）を共通経路で扱う構成の設定と制約。個別の契約は各媒体の文書が正本で、この文書は横断の条件と合成previewによる検証手順をまとめる。2026-10-04の隔離複製検証の記録は[archive](archive/M5-隔離複製検証の記録.md)にある。

## 契約と管理場所

画像4・動画4・音声4の固定ID、媒体別入力・出力、独立した上流確認gateを維持する。[共通ジョブ](M1-共通メディアジョブと保持.md)、[素材・画像](M2-素材基盤と画像4モデル.md)、[動画](M3-通常動画4モデルとprivate再生.md)、[音声](M4-音声4モデルとprivate再生.md)が個別契約の正本。

| 項目 | M-5で維持する条件 |
| --- | --- |
| 新規生成 | `ENABLE_MEDIA`と12固定IDの`MEDIA_ALLOWED_MODELS`。さらに媒体ごとの`MEDIA_VERIFIED_*_MODELS`を照合。省略・空の確認一覧は未確認として拒否 |
| 全OFF | 公開wrangler・5設定例はfalse/空一覧。FAL_KEYと追加R2なしで標準起動可能。AI/Jev/旧画像とは独立 |
| 生成画像の動画再利用 | 同じ素材ID・版・最初の検証時刻/30日期限。参照10 MiB/寸法/画素/合計50 MiBと残り30分を再照合。コピー・延長・変換を追加しない |
| 配信 | 所有者session、ready/期限/版を確認後にprivate/no-store配信。動画/WAV/MP3は単一Range、強いETagのIf-Range、HEAD、416。未認証/別所有者へvalidator・サイズを返さない |
| 利用・容量 | 新旧合算の所有者1件/環境3件。失敗/取消の消費を戻さず、受付不明は同時/最大容量も保持。物理削除確認後だけ容量を解放 |
| 保持・復旧 | 本文はアプリ終端30日、最小台帳90日。未終端/受付不明を日数で解放しない。復元前の正しいwitnessと上流/削除照合なしではgateを解除しない |

M-5自体はSQL・実リソース・Cron・automationを追加しない。

## 統合試験と合成preview

[統合試験](../tests/media-integration.test.ts)は実API dispatch・合成session・共通driverから固定adapter、隔離workerd/D1/R2まで通す。12正常系には固定送信ヘッダー、private保存、同ID再取得/異入力409、利用1件、最大予約から実容量への置換、未認証/別所有者拒否、Range、削除/容量解放を含む。未確認gate12件、許可外12件は予約・通信0。生成画像→動画3経路のID/版/期限不変・終端grant失効、画像受付不明→動画/TTS/音楽の共有枠停止、追加R2/キーなしOFFも検査する。

媒体別の既存試験も`pnpm test`で再実行する。素材ID/版/期限/grant、容量競合、新旧枠/要求ID、部分回収/receipt、取消・削除・遅いwriter、本文30日/台帳90日、復旧witness、空DB/upgrade/再適用/失敗DDLの回帰を含む。試験の断線・Workflow失敗注入による診断行を、失敗したassertionと混同しない。

[合成fake](../tests/media-integration-fake.ts)と[専用Worker](../tests/media-integration-preview-worker.ts)は固定fake以外のfetchを拒否し、provider取得grantも実D1/R2で照合する。PNG/青一色MP4/無音WAV・MP3だけを使う。[HTTP smoke](../scripts/media-integration-smoke.mjs)は`/__m5-fixture`のmarkerを必須にし、12件の受付/待機/同ID再取得/回収・private配信/Range/削除/logout、生成画像の動画再利用と期限不変を確認する。動画3要求/所有者の上限を変えず、4件目は別の合成所有者を使う。

合成設定は公開wranglerから管理外の`.wrangler/m5-preview/wrangler.jsonc`へ生成する想定で、この生成を行うscriptはリポジトリにない（Viteの[専用config](../tests/media-integration-preview.config.ts)が参照する）。実行先はlocal、公開経路なし、外部呼出しはfakeのみ、上流gateとFAL_KEYは明示的なTEST_ONLYダミー。ViteのpersistState.pathとWranglerの`--persist-to`は同じ`.wrangler/m5-preview/state`へ揃え、`remoteBindings: false`を指定する。公開OFF版は[別config](../tests/media-off-preview.config.ts)で`.wrangler/m5-off/state`を使う。元利用DBは使わない。

## 残る制約

実fal/AI/Jev/メール/決済・課金、クラウド/Access/R2の作成変更、配備、Secret操作は、この検証の対象外。上流のStore-IO/ACL/保持/回収/利用権限が未確認の実モデルは引き続き拒否し、公開保存・別endpointへ切り替えない。

Geminiの保守的受付をモデル固有token実測、wrapper込みの上限証明として扱わない。MP4/MP3の構造検査を全フレーム/全波形・知覚品質保証へ広げない。上流の全コピー消去や停止中の物理回収も保証しない。実接続は[実接続前の停止条件](operations.md#実接続前の停止条件)で対象・素材・予算・回数・期間・終了条件を決めた後に、別承認で行う。

公式根拠と固定版照合は[M-5のローカル隔離手順](../references/m5-local-isolation-20261004.md)を参照する。
