## 入口と管理場所

devなら[分類画面](http://127.0.0.1:3000/decisions)、build済みpreviewなら[分類画面](http://127.0.0.1:4173/decisions)へ進む。ヘッダーの「依頼の分類」からも開ける。起動・架空登録は[local手順](presets/local.md#次の操作)を使い、API操作の前には同じoriginの`/app`でログインする。fixtureを見るだけならログイン不要。APIの所有権確認を省略する入口ではない。

画面は`src/routes/decisions.tsx`と`src/components/decision-example.tsx`、通信・検証・合成例は`src/lib/decision-example.ts`で管理する。サーバーは既存の`src/server/decisions/`をそのまま使用し、HTTPは固定分類POSTと本人metadata GETだけ。新しい汎用質問APIや設定生成は追加しない。

`/decisions`はSSR・noindex/nofollow・no-store・no-referrer。事前生成対象に加えず、SSRへ利用者の入力や結果を埋め込まない。公開例のJEV_MODE=off、キーなし起動、RAG/agentを含む全拡張OFFを維持する。チャットから自動で呼ばず、チャットモデルや認証方式を切り替えない。

## 接続せずに試す

「計画整理の合成例」「該当なしの合成例」「不確実な合成例」は固定の架空入力と合成fixture。ボタンは表示だけを変え、推論・POST・台帳への登録をしない。初期画面のログイン状態確認は既存のsession GETだけである。

合成例はAPIの代替結果へ使わない。実Jevの精度・確率・confidence計算・usage・日本語品質の測定値ではない。`none`は候補外・材料不足・主目的が決められない場合の通常結果とする。選択と全4候補の確率・confidenceを応答値のまま表示し、独自式や未評価の閾値で補正・自動採用しない。常に人が確認し、認可や外部操作の承認に使わない。

## APIへ依頼するとき

この文書・画面の存在は実接続の許可ではない。実契約・送信可能データ・保持/削除・unknown修復・費用・権限・品質・人数/総予算/期間/終了方法は[工程E前の停止条件](operations.md#工程e前の停止条件)として未解消のまま。C-Jの検証は既定OFFとfake境界だけで、JEV_MODE/固定版/Secretを変更していない。

別承認後の設定済み環境でのみ、ログイン→短い本文を入力→送信先/費用の承認済み確認→「分類を1回依頼する」の順で手動POSTする。画面のチェック欄は接続許可やアプリ認可の代わりにならず、サーバーのguard・所有権・独立枠が正本。入力は1〜2,000 Unicode code points・UTF-8 8,000 bytes以内で、自動trim/NFC変換/切詰めをしない。本文の機密・個人情報は自動除去されず、有効な接続では上流へ送られる。

要求キーはクリック時のUTC日とUUIDv4。POSTは1回だけで、redirect・自動retry・別provider/modelへのfallbackをしない。初期OFFは未接続と表示し、fixtureへ代替しない。日付不一致でもキーを自動更新しない。成功応答の契約版/固定版/4候補/確率/usage/人の確認/再表示不可/要求キーを検証し、不正・紛失は結果不明として停止する。

## 応答紛失と状態確認

要求キーを本人が控えた場合は、同じ画面の「状態だけ確認する」で手動GETできる。自動pollなし、5秒以内の連続操作を抑止する。サーバーは所有者60要求/UTC分の既存上限を維持し、要求台帳を更新せず利用制限counterだけを更新する。

応答紛失・timeout・ledger不明・処理中・unknownでは、新しい依頼ボタンをロックする。同じキーの本人GETがsucceeded/failedを返した場合だけ、明示の別依頼へ進める。別キーの終端、GET失敗、不存在/保持期限後を解除根拠にしない。GETは結果を返さず、成功でも結果再表示不可。別依頼には新しい要求・再課金の可能性を表示し、確認操作が必要。unknownの自動再送・削除・同時枠解放は追加しない。

本文・結果・要求キーは画面メモリだけに置き、localStorage/sessionStorage、URL、会話履歴、R2等へ保存しない。再読み込み・画面移動で失われる。画面を離れても上流停止・未課金を保証せず、キーの紛失を新しいキーや再送で救済しない。backup復元後は照合完了までJev OFF・受付停止という既存契約を維持する。
