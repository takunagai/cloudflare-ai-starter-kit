# 共通開発ルール案

更新日: 2026-09-27。ユーザーの `/init 日本語で` により、下記の案を実装と照合して [AGENTS.md](../AGENTS.md) に統合した。今後の共通開発ルールの正本はAGENTS.mdとし、この文書は第1段階の草案として保存する。検証結果はREADMEと作業記録を参照し、この文書だけで成功扱いしない。

## 段階と実装範囲

- 第1段階は開発環境・最小画面・Worker疎通・品質検証・運用手順まで。認証、AIチャット、履歴、任意拡張は第2段階で実装する。
- 第1段階の完了報告後は停止し、ユーザーの環境確認と `/init 日本語で`、明示の再開指示を待つ。Goal全体を完了扱いしない。
- TanStack Startを採用し、基本のルーティング・データ取得・サーバー関数から始める。ExperimentalなReact Server Componentsは導入しない。
- 単一パッケージ・主Workerを基本とする。独自CLI、汎用プラグインローダー、不要な抽象化を追加しない。
- 既存変更や別セッションの成果物を無断で破棄しない。変更は目的に必要な範囲に絞る。

## ツールと依存

開発・CIはNode.js 26.10.0、pnpm 12.6.0を使用する。サーバー実行環境はCloudflare Workersのworkerd。Node上の成功だけでWorkers互換と判断しない。

依存は `package.json` と `pnpm-lock.yaml` を一緒に管理する。CIと複製検証は `pnpm install --frozen-lockfile` を使う。npmや別のパッケージマネージャーのlockfileを混在させない。

新規依存・更新時は公式の対応環境、peer、ライセンス、脆弱性情報を確認する。Beta許容はExperimentalの包括承認ではない。採用済み技術の互換更新と、構成を変える新技術の導入を区別する。

## 日常のコマンド

| コマンド | 用途 |
| --- | --- |
| `pnpm dev` | ローカル開発サーバーを127.0.0.1:3000で起動 |
| `pnpm build` | 本番用成果物を生成 |
| `pnpm preview` | ビルド後の成果物を127.0.0.1:4173で確認 |
| `pnpm format` | Biomeでコードの整形・修正 |
| `pnpm lint` | Biomeの検査。ファイルを書き換えない |
| `pnpm typecheck` | Workers bindings型とroute型を生成し、TypeScript検査 |
| `pnpm test` | Workers向けテストを実行 |
| `pnpm check` | lint、typecheck、test、buildを順に実行 |
| `pnpm smoke` | HTTP疎通の確認。起動条件・対象URLは実装とREADMEに従う |
| `pnpm audit` | 公開脆弱性情報と依存を照合。外部レジストリへ接続する |

スクリプト定義の正本は `package.json`。ビルド・型生成で生成されるファイルは手編集しない。ローカルHTTPとCIの成功、実クラウドの成功を分けて記録する。

## 秘密とデータ

この草案の秘密関連ルールはユーザーレベルの共通ルールへ統合した。ここでは重複管理せず、Cloudflare固有の事項だけ [Secrets運用補足](../rules/secrets.md) に残す。認証・所有権・公開データの境界は [AGENTS.md](../AGENTS.md) と構成資料に従う。

## 検証の原則

変更が影響する挙動を検証する。第1段階はHTTPの正常/異常入力、method、content type、未知API、SSR本文と疎通を対象とする。実装を写しただけのテストや、低影響の文書変更のためだけの新規テストは増やさない。

通常CIは外部LLM、メール配信、課金処理を実行せず、デプロイもしない。第2段階では外部境界をfakeにし、認証・所有権・SQL・HTTPの重要部分を実際のローカルWorkers/D1で検証する。任意拡張は全OFFでも標準機能が起動することを確認する。

実接続・有料処理・外部リソース変更・公開には、対象環境、内容、回数、見積り、必要なら上限を具体化する。許可済みの範囲は再確認せず進めるが、ローカル検証の許可をクラウド変更の許可に読み替えない。

## 変更と報告

何を変えたか、理由、実際に行った検証、未検証の範囲を簡潔に残す。失敗や実施不能を成功へ読み替えない。依存・コマンド・設定を変更したらREADMEと [運用手順](operations.md) の整合も確認する。
