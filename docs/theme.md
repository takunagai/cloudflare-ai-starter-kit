# 見た目とテーマ設定

確認日: 2026-10-19

## 方針

- 装飾は最小限。既定はモノクロ（無彩色のグレーと黒・白のアクセント）。
- 配色の基準値は `src/theme.css` に集約する。`src/styles.css` は役割ごとのトークン（`--bg`、`--surface`、`--text`、`--accent` など）へ割り当てるだけで、色コードを直書きしない。
- 本文フォントはOS標準フォント（Webフォントを読み込まない）。

## テーマカラーの変え方

`src/theme.css` の `:root` を編集する。

| 変数 | 役割 |
| --- | --- |
| `--theme-accent` / `--theme-on-accent` | ライト表示のアクセントと、その上の文字色 |
| `--theme-accent-dark` / `--theme-on-accent-dark` | ダーク表示のアクセントと、その上の文字色 |
| `--theme-neutral-chroma` / `--theme-neutral-hue` | 背景・文字・境界線のグレーに混ぜる色味（chroma 0 で無彩色） |
| `--theme-radius` | 角丸の基準値 |

アクセントはボタン・ブランドマーク・フォーカス枠・選択状態・チェックボックスに使われる。ホバー色や薄い背景は `color-mix()` で自動派生する。ブルー・グリーンの設定例はファイル内のコメントにある。

エラー（赤）・注意（黄）・成功（緑）の状態色は意味を保つためテーマに連動させず、`styles.css` で固定している。

Tailwindのユーティリティ（`bg-accent`、`text-muted-foreground`、`border-border` など）と `dark:` もこのトークンとテーマ切替に連動する。

## ダーク表示

- 既定はOS設定（`prefers-color-scheme`）に追従する。
- ヘッダーの切替ボタンで「自動 → ライト → ダーク」を巡回する。固定した値はブラウザの `localStorage`（キー `theme`）に保存し、「自動」に戻すと削除する。保存できない環境でも表示中のページには反映する。
- 初期表示のちらつきを防ぐため、`src/routes/__root.tsx` の `head().scripts` で hydration 前に `data-theme` を付ける。
- 色は `light-dark()` で定義している。build時にLightning CSSが旧ブラウザ向けの変数方式へ変換する。

## 変更時の注意

- アクセントを変えたら、ライト・ダーク両方でボタン文字のコントラスト（4.5:1以上）を確認する。
- インラインscriptを禁止するCSPを導入する場合は、初期化scriptにnonceまたはhashを付ける。付けないとダーク固定時に初期表示が一瞬ライトになる。
