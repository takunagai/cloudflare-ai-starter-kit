## 無料枠なしの費用見積り

単価は2026-09-28の[公式料金](https://developers.cloudflare.com/workers-ai/platform/pricing/)に基づくUSD・税別。第一候補は入力$0.152/100万tokens、出力$0.287/100万tokens。無料枠、cache割引、短い実入力による減額を当てにしない。

**AI推論分は約$0.016、申請上の目安$0.02**。無料枠が全く残っていなくても、この入出力・回数条件なら上記の計算となる。実請求はNeuronsで行われ、公式換算単価・丸め等により差がある。約10,000 Neurons/日の無料枠残量、他アプリの共有使用量、現在のPaid状態・請求方法、利用権限は今回は未確認。過去のPaid確認を現在の契約確認に読み替えない。

基盤側の全含有枠も消費済みと仮定した参考計算は、動的HTTP 30回、CPU合計900,000 ms、D1読取10,000行・書込1,000行・追加保存0.001 GB-monthなら、Workers $0.018009、D1 $0.001760、AI込み約$0.0353。根拠・式は[調査](../references/workers-ai-minimal-verification.md)。これは基盤の実測値でも、強制上限でもない。UI再読込・集計SQL・index更新も基盤使用量に入る。実行前に既存DB規模とCPU制限を確認し、この前提を超える見込みなら再見積りする。

## 最大3回の確認手順

ログイン済みの本人ブラウザ1タブで行い、自動テスト、別タブ、リロード再送を併用しない。認証済み同一originのアプリ経由のみ。認証ヘッダーやCookieを取得したcurlへ転用しない。各送信前に残枠・対象モデル・入力と履歴byte数を確認する。

ローカルの文字数計算では、現行固定systemはUTF-8 366 bytes、下記入力は順に55/40/57 code units・159/116/163 bytesだった。履歴なしのsystemとの合計は525/482/529 bytes。2回目はこれに実際の履歴が加わるため、実施時に再計算する。この計算はtoken数や課金実績の計測ではない。

| 枠 | 非機密テスト入力 | 目的・次へ進む条件 |
| --- | --- | --- |
| 1 | `これは接続テストです。架空の箱には赤い玉が2個、青い玉が3個あります。合計を日本語の短い1文で答えてください。` | 新規会話Aで送信。HTTP/SSE、非空の応答、5個という内容、エラーなし、`finish`と保存後completeを確認。完了後1回reloadして一覧からAを選び、user/assistantが各1件で一致することを確認 |
| 2 | `先ほどの箱から青い玉を1個取り出しました。残りの合計を短い1文で答えてください。` | Aを復元後に送信。直前2メッセージだけを履歴に含むこと、入力総量が上限内であることを先に確認。4個という応答と、reload後user/assistant各2件・順序・本文一致を確認 |
| 3 | `接続テスト用です。番号1から10までを1行ずつ書き、各行に「確認しました」と付けてください。ほかの説明は不要です。` | 必要な場合のみ新規会話Bで送信。完了前に複数deltaで本文が増えることを観測。先の2回で逐次表示まで確認できたら使わず終了可 |

1回目や2回目の失敗で残りを自動消化しない。結果不明も消費済みとして停止し、残枠内の再試行は原因解決・条件再確認後に限る。1枠を再試行へ使えば上表の後の試験を省き、未検証項目を明記する。4回目は実モデルを呼ぶ試験にせず、fakeで制御済みであることを前提とする。

SSE `start`→1件以上の`delta`→`finish`、エラーなし、保存・reload一致で応答経路を合格とする。**逐次表示は別判定**とし、少なくとも1回で異なる時点の複数deltaと完了前のUI更新を確認する。短文が一括で到着しただけならstreamingは未確認。上流生成の逐次性まで厳密に区別する必要がある場合は、非stream結果をproviderが包んでいる可能性があるため、本文を保存しない種別計測の追加案を別途レビューする。

完了後、作成したA/BだけをUIで削除する。GETで一覧から消え、再読込後も復活せず、同じ会話の認証済み取得が404になることを確認する。既存会話は削除しない。許可済みのD1集計照会で、この試験の会話・messagesが0件、`chat_requests`は消費分が残ることを件数だけ確認する案とする。実requestIdやowner値を文書へ出さない。D1集計の権限や安全な手段が未確定ならSQLを実行せず「API削除のみ確認、DB直接確認は未検証」とする。

## 停止条件・判定・後処理
